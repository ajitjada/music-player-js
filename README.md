# 🎵 Spotify Clone - Music Player
A responsive web-based music player built with **HTML**, **CSS**, and **JavaScript** featuring play/pause, next/previous controls, seek bar synchronization, volume control, dynamic playlists, and a modern user interface.

---


## ✨ Features

### 🎶 Music Player
- Play/Pause songs
- Next & Previous song
- Auto Play next track
- Seek/Progress bar
- Song duration & current time
- Volume control

### 📂 Music Library
- Dynamic song list
- Local MP3 playback
- Playlist cards
- Scrollable music library

### 🎨 User Interface
- Responsive layout
- Sidebar navigation
- Smooth hover animations

---


## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- HTML Audio API


```bash
cd spotify-clone-project
```
